# Web Scraping Projects

This repository contains sample Python projects that demonstrate skills in web scraping using libraries like `requests`, `BeautifulSoup`, and `csv/json`.

---

## Projects

### 1. Amazon Scraper
- Extracts product name, price, and rating from a sample Amazon page.
- Simulates real-world product tracking.

### 2. LinkedIn Companies Scraper
- Extracts company names and industries from simulated LinkedIn HTML.
- Useful for business data collection practice.

### 3. News Aggregator
- Collects latest headlines from CNN and BBC.
- Great intro to scraping news portals.

---

## Technologies Used
- Python
- requests
- BeautifulSoup
- csv & json
